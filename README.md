# Watch Weather – Android (Capacitor)

720p (1280×720) landscape clock + live weather station.
Clock ⇄ Pitești rotate every 20 s; Valea Mare and Arefu open only from the location buttons
(and return to the clock after 20 s without interaction).

Weather: Open-Meteo (https://api.open-meteo.com/v1/forecast) – current, hourly, 7-day daily.
Refresh: every 15 min + on app resume + when the network comes back.
Offline: last successful response per location is cached with @capacitor/preferences;
the status line shows "Updated HH:MM · Offline data" when a refresh fails.

## Requirements
- Node.js 20+
- Android Studio (latest stable) with Android SDK, JDK 21 (bundled with Android Studio)

## Build
```bash
npm install
npm run build
npx cap add android
npx cap sync android        # also runs scripts/configure-android.mjs automatically
npx cap open android
```
In Android Studio: **Build > Build APK(s)** → `android/app/build/outputs/apk/debug/app-debug.apk`.

For a release APK: **Build > Generate Signed App Bundle / APK > APK** (create/use a keystore).

If the automatic hook did not run, apply the native settings manually and sync again:
```bash
npm run android:configure
npx cap sync android
```

After any change in `index.html` / `src/`:
```bash
npm run android:sync
```

## What `scripts/configure-android.mjs` sets
- `android:screenOrientation="sensorLandscape"` on MainActivity (landscape only)
- `INTERNET` and `ACCESS_NETWORK_STATE` permissions
- MainActivity: keep screen on + immersive full screen (system bars hidden)
- Optional HOME launcher intent filter (`package.json → watchWeather.kioskLauncher`)

## Dedicated weather-station setup (tablet / TV box)
1. Keep the device permanently on power.
2. Auto-start after restart: with `kioskLauncher: true`, press **Home** once and choose
   **Watch Weather → Always**. The app becomes the home screen, so it opens automatically after every reboot.
   Set `kioskLauncher` to `false` (then `npx cap sync android`) on a personal phone.
3. Screen pinning: Settings → Security → **App pinning / Screen pinning** → On, open the app,
   Recent apps → app icon → **Pin**.
4. Exclude the app from battery optimisation: Settings → Apps → Watch Weather → Battery → **Unrestricted**.
5. Set Settings → Display → Screen timeout to the maximum (the app also keeps the screen on while open).
6. Make sure automatic date/time and time zone are enabled (the clock uses the device time).
